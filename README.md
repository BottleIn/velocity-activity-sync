# velocity-activity-sync

Jira 의 **`활동비` 이슈 유형** 티켓을 팀 활동비 Google Sheets 로 자동 동기화하는 Apps Script.

- **원본은 Jira.** 사람은 Jira 티켓에만 입력한다.
- **시트는 거울.** `jira_sync` 탭(원료)과 월별 탭 07월~12월(표시)이 1시간마다 갱신된다.
- **시트의 수기 영역은 보존한다.** 티켓 링크 없는 행, No.·순지출액·증빙 URL·비고 열은 건드리지 않는다.

> 실제 시트 URL·티켓 번호 등 팀 내부 값은 이 README 에 두지 않는다.
> 팀 Confluence 의 "프로젝트 활동비" 문서에 있다.

## 동작 방식

```
Jira 활동비 티켓
   │  1시간 트리거(scheduledSync) 또는 메뉴 [지금 동기화 (월별 탭까지)]
   ▼
jira_sync 탭   ← 전량 재작성 (직접 고치면 다음 동기화에 사라짐)
   │  배정월 = 결제일의 월, 결제 전이면 신청일의 월
   ▼
07월~12월 탭   ← 행 단위 upsert (표·서식·수기 행 보존)
```

- **월별 탭 upsert 키 = 티켓 링크**(신청서 URL 열에 자동 기입). 링크가 있는 행만 스크립트 소유로
  보고 갱신·정리하며, 링크 없는 행은 수기 행으로 절대 건드리지 않는다.
- 티켓의 결제일이 바뀌면 다음 동기화 때 원래 달 탭에서 비워지고 새 달 탭에 들어간다.
- Jira 조회가 실패하면 시트를 지우지 않는다. `jira_sync` 1행에 오류만 남고 직전 데이터가 유지된다.
- 시트가 계산·수기로 관리하는 것: No., 순지출액(수식), 증빙 URL, 비고.
- 환불은 별도 티켓(`[환불] 원 품목명`, 실제 결제액 음수), 취소는 `활동비 상태 = 취소`.

## Jira 쪽 준비물

team-managed 프로젝트에서 **전용 이슈 유형 `활동비`** 를 만들고(개발 티켓에 빈 칸이 달라붙지 않게),
그 유형에만 커스텀 필드를 붙인다. **필드 이름이 코드(`Config.gs`)와 글자 단위로 같아야 한다** —
스크립트가 ID 가 아니라 이름으로 필드를 찾는다. 이름이 다르면 그 열만 조용히 빈다.

| 필드명 | 타입 | 옵션 |
|---|---|---|
| 지원 항목 | 드롭다운 | 클라우드 서비스 / AI·SW 서비스 / 재료 구매비 / 마케팅비 / 개발자 등록비 / 기타 |
| 활동비 상태 | 드롭다운 | 신청 예정 / 승인 대기 / 승인 완료 / 결제 완료 / 취소 |
| 신청일 · 승인일 · 결제일 · 증빙 기한 | 날짜 선택 | 날짜/시간 아님 |
| 신청금액 · 실제 결제액 | 숫자 | 환불은 음수 |
| 결제 방식 | 드롭다운 | 법인카드 / 개인카드 / 계좌이체 / 기타 |
| 증빙 상태 | 드롭다운 | 미제출 / 일부 제출 / 보완 요청 / 완료 |

- 요약(품목·서비스)·담당자·티켓 링크는 기본 필드라 만들 필요 없다.
- 신청서·증빙 URL 필드는 두지 않는다 — 증빙 원본은 티켓 첨부 파일이 담당한다.
- 진행 상태는 워크플로 status 가 아니라 드롭다운 `활동비 상태` 로 관리한다
  (워크플로를 건드리면 같은 프로젝트의 개발 보드까지 영향을 받는다).
- 없는 필드가 있어도 해당 열만 비고 나머지는 정상 동작한다. 필드를 새로 만들면
  다음 동기화 때 매핑이 자동 갱신된다.

## 배포

```bash
npm install -g @google/clasp   # clasp 3.x
clasp login
```

1. 대상 시트(네이티브 Google Sheets 여야 한다 — .xlsx 는 Apps Script 를 붙일 수 없다)에서
   **확장 프로그램 > Apps Script** 로 바인딩 프로젝트를 만들고 주소창에서 scriptId 를 복사한다.
   (`clasp create --parentId` 는 새 시트를 만들어버릴 수 있어 시트 쪽에서 먼저 만드는 편이 확실하다.)
2. `.clasp.json` 을 만든다: `{ "scriptId": "<scriptId>", "rootDir": "./src" }`
3. `clasp push` — 계정에서 [Apps Script API](https://script.google.com/home/usersettings) 를
   먼저 켜야 한다. push 는 편집기 파일 목록을 로컬 `src/` 로 통째로 맞추므로 수정은 항상 로컬에서.

시트를 새로고침하면 **[활동비 동기화]** 메뉴가 생긴다:

1. **설정...** — Jira 사이트, 계정 이메일, API 토큰([발급](https://id.atlassian.com/manage-profile/security/api-tokens)),
   프로젝트 키, 이슈 유형 이름. **토큰은 Script Properties 에만 저장된다. 코드·git 에 절대 넣지 않는다.**
2. **연결 테스트** — 인증 / 필드 매핑 / 대상 티켓 수를 한 번에 확인.
3. **지금 동기화 (월별 탭까지)** — jira_sync 재작성 + 월별 탭 반영, 탭별 신규·갱신·제거 건수 알림.
4. **자동 동기화 켜기 (1시간)** — `scheduledSync` 시간 트리거 설치.

## 파일 구성

```
src/
├── appsscript.json   매니페스트 (Asia/Seoul, OAuth 스코프)
├── Config.gs         열 정의 · Script Property 키 · 기본값
├── FieldMap.gs       Jira 필드 이름 → customfield_NNNNN 해석 · 캐시 · 자동 갱신
├── JiraClient.gs     /rest/api/3/search/jql 호출 + nextPageToken 페이징
├── SyncSheet.gs      jira_sync 탭 전량 재작성 · 값 변환(날짜 시리얼 등)
├── MonthlyView.gs    월별 탭(NN월) 행 단위 upsert · 검증 복사
├── Menu.gs           시트 메뉴 · 시간 트리거
└── Setup.gs          설정 마법사 · 연결 테스트
```

`jira_sync` 탭: 1행 상태 줄, 2행 헤더, 3행부터 데이터. 열 순서는 이슈키 · 품목·서비스 ·
지원 항목 · 활동비 상태 · 신청일 · 승인일 · 결제일 · 신청금액 · 실제 결제액 · 결제 방식 ·
담당자 · 증빙 기한 · 증빙 상태 · 티켓 링크 · 배정월.

## 값 변환 메모 — 삽질의 기록

Google Sheets 에 값을 "정확히 그대로" 넣는 건 생각보다 어렵다. 전부 실제로 겪은 것들이다.

- **날짜는 시리얼 넘버로 쓴다.** Date 객체는 "시각"이라 스크립트 시간대(Asia/Seoul)의 0시가
  문서 시간대에 따라 전날로 표시된다(결제일이 하루 밀리는 버그). 문자열은 `setValues` 가
  타이핑처럼 해석해 로케일에 따라 달라진다. 1899-12-30 기준 일수(시리얼)만이 무조건 안전하다.
- **`'2026-07'` 같은 텍스트는 날짜로 자동 변환된다.** 배정월 열은 쓰기 전에 서식을 `@`(일반 텍스트)로
  고정해야 문자열 비교가 성립한다.
- **표(Table) 안에서는 여러 열에 걸친 서식 변경이 거부된다**
  ("열 수준 작업을 수행하려면 단일 열에서 선택하세요"). 서식은 한 셀씩 지정하고, 실패해도 무시한다.
- **표 밖(또는 검증이 지워진) 행에 쓴 값은 드롭다운이 안 뜬다.** 같은 열에서 검증 규칙이 살아 있는
  셀을 찾아 `copyTo(..., PASTE_DATA_VALIDATION)` 으로 복사해 살린다.

## 동작 메모

- 대상 JQL: `project = <키> AND issuetype = "<유형>" ORDER BY created ASC`.
  다른 조건이 필요하면 Script Property `JQL_OVERRIDE` 가 우선한다.
- 검색은 `/rest/api/3/search/jql`. 구 `/rest/api/3/search` 는 제거되어 410 을 반환한다.
  페이징은 `nextPageToken` 이고 `fields` 를 명시하지 않으면 필드가 오지 않는다.
- 필드 매핑 캐시에 빠진 이름이 있으면 동기화가 스스로 다시 받아온다.
  수동 확인은 메뉴 **Jira 필드 매핑 확인**.
- 트리거는 스크립트 소유자 계정 권한으로 돈다. Atlassian API 토큰 만료일(최대 1년)을
  캘린더에 걸어두면 조용한 중단을 막을 수 있다.

## 문제 해결

| 증상 | 원인 / 조치 |
|---|---|
| `Jira API 401` | 토큰 만료 또는 이메일 불일치 → 설정에서 재등록 |
| `Jira API 410` | 구 검색 엔드포인트 호출 → `/search/jql` 사용 확인 |
| 특정 열만 계속 비어 있음 | Jira 필드 이름이 `Config.gs` 의 `jiraField` 와 다름 → 필드 매핑 확인 |
| 월별 탭에 안 들어감 | jira_sync 배정월 열이 비어 있음 → 티켓에 결제일 또는 신청일 입력 |
| 드롭다운이 안 뜸 | 검증 없는 행에 기입됨 → 다음 동기화 때 자동 복원 |
| 날짜가 하루 밀림 | 옛 버전 데이터 → 지금 동기화 한 번이면 시리얼 값으로 재기입 |
| 확장 프로그램 > Apps Script 안 열림 | 파일이 아직 `.xlsx` → 네이티브 Sheets 로 변환 |
| 티켓을 지웠는데 시트에 남음 | 자동 동기화 꺼짐 → 자동 동기화 상태 확인 |
